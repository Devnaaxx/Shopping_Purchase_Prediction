🛍️ Shopping Addiction & Purchase Prediction

Machine Learning Project

📌 About the Project

A Machine Learning project that predicts whether an online shopping visitor will make a purchase based on their browsing behaviour.

🤖 Algorithms Used

* Logistic Regression
* Decision Tree
* Random Forest

🛠️ Technologies

* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Scikit-learn
* Streamlit

 Features

* Purchase behaviour prediction
* Purchase probability estimation
* Model comparison
* Interactive user interface

 Model Evaluation

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix

 Run the Project

pip install -r requirements.txt
streamlit run app.py
